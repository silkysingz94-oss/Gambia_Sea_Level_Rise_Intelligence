Methodology & limitations

1. EA polygons are filtered using the actual supplied attributes.

2. Population and household totals are calculated from the selected source attributes, where available.

3. A DEM is sampled across the selected geography. Terrarium RGB values are decoded to elevation values.

4. Grid cells with elevation at or below the scenario threshold are highlighted as potentially inundated.

5. EA centroid elevation is used for a basic EA screening indicator. Population in flagged EAs is not a count of people actually flooded.

This is not a hydraulic or hydrodynamic model. It does not simulate wave action, river discharge, tidal propagation, drainage, embankments, coastal barriers, erosion, subsidence or connectivity to the sea. DEM vertical datum and baseline water-level compatibility must be verified before interpreting absolute elevations.
